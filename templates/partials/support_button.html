{% comment %} Floating "Contact Support" button, included by base.html so it is available on every page. Behaviour lives in static/js/support.js; this markup only declares it: * the link opens the ADMIN chat specifically — the dashboard's chat page with ?support=1, which chat.js resolves to the Support conversation (or to the Support contact when no thread exists yet). Logged out, the visitor is sent to the login form carrying ?next= back to that same destination; * dragging is vertical only: the button is pinned to the trailing edge (right in LTR, left in RTL — one logical inset, mirrored by the browser) and only its height follows the pointer, clamped to the viewport; on release it keeps the released height and glides into place through a CSS transition class. The anchor is explicitly draggable="false": a plain is natively draggable, and the browser's own drag cancels the pointer events the drag is built on; * the minus control minimizes it to a small bubble on the same spot, and that bubble carries a dedicated expand control to come back — restoring never relies on a double click, so a double click stays free to open the chat. The state (side, height, minimized) is remembered in localStorage. {% endcomment %} {% load i18n static %} {% trans "Contact Support" %}
